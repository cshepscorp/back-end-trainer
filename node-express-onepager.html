Node.js & Express

Backend fundamentals · Reference sheet
The runtime

Node.js

A JavaScript runtime built on Chrome's V8 engine. It lets you run JavaScript outside the browser — on a server, your local machine, or anywhere with an OS. It bundles V8, an event loop, and system-level modules (file system, networking, crypto) into one package.

The library

Express

A lightweight npm library that runs inside Node.js. It wraps Node's raw http module with a friendlier API: clean routing, middleware chaining, and response helpers. Express cannot run without Node.js — it is not a runtime.

The analogy
Node.js is the engine. Express is the frame, steering wheel, and dashboard.
→
What that means
You could drive the engine directly. But you'd be building the car as you go. Express gives you the scaffolding so you can focus on where you're driving.

The same server — with and without Express

// Raw Node.js http module const http = require('http'); const server = http.createServer((req, res) => { if (req.url === '/parks' && req.method === 'GET') { res.writeHead(200, { 'Content-Type': 'application/json' }); res.end(JSON.stringify({ parks: [] })); } // manual routing, body parsing, // error handling... all yours to write }); server.listen(3000);
Without Express — verbose, manual
// With Express const express = require('express'); const app = express(); app.use(express.json()); // body parsing app.get('/parks', (req, res) => { res.json({ parks: [] }); }); app.post('/parks', (req, res) => { // req.body already parsed const park = req.body; res.status(201).json(park); }); app.listen(3000);
With Express — routing, parsing handled

A request's journey through Express

01
HTTP request arrives
A client sends GET /parks to your server on port 3000
02
Node receives it
Node's http module accepts the raw TCP connection and parses headers
03
Express middleware
Request passes through middleware: logging, auth, body parsing, CORS
04
Route handler
Express matches the path + method and runs your handler function
05
Response sent
res.json() serializes data and Node writes bytes back to the client
Does Express work without Node?

No. Express is a Node.js library. It uses Node's http module internally and has no runtime of its own.

Could you use something other than Express?

Yes. Fastify, Koa, and Hono are popular alternatives — all Node.js libraries with different trade-offs in speed, API style, and TypeScript support.

What does middleware actually do?

Functions that run between the request arriving and your handler executing. Each one can read, modify, or short-circuit the request. They chain in order of app.use() calls.
