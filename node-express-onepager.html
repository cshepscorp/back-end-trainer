Node.js & Express

What Node.js actually is, what Express adds on top of it, and how a request moves through both — with code.

What each one is
The runtime

Node.js

A JavaScript runtime built on Chrome's V8 engine. Lets you run JavaScript outside the browser — on a server or local machine. Bundles V8, an event loop, and system-level modules (file system, networking, crypto).

The library

Express

A lightweight npm library that runs inside Node.js. Wraps Node's raw http module with a friendlier API: routing, middleware chaining, and response helpers. Cannot run without Node.js — it is not a runtime.

The analogy
Node.js is the engine. Express is the frame, steering wheel, and dashboard.
→
What that means
You could drive the engine directly — but you'd be building the car as you go. Express gives you the scaffolding so you focus on where you're going.
The same server — with and without Express
// Raw Node.js — verbose, manual const http = require('http'); const server = http.createServer((req, res) => { if (req.url === '/parks' && req.method === 'GET') { res.writeHead(200, { 'Content-Type': 'application/json' }); res.end(JSON.stringify({ parks: [] })); } // manual routing, body parsing, // error handling... all yours }); server.listen(3000);
Without Express — everything is manual
// With Express — clean and concise const express = require('express'); const app = express(); app.use(express.json()); // body parsing app.get('/parks', (req, res) => { res.json({ parks: [] }); }); app.post('/parks', (req, res) => { // req.body already parsed const park = req.body; res.status(201).json(park); }); app.listen(3000);
With Express — routing and parsing handled
A request's journey through Express
01
HTTP request arrives
Client sends GET /parks to your server on port 3000
02
Node receives it
Node's http module accepts the raw TCP connection and parses headers
03
Express middleware
Request passes through middleware: logging, auth, body parsing, CORS
04
Route handler
Express matches path + method and calls your handler function
05
Response sent
res.json() serializes data, Node writes bytes back to the client
Key questions answered
Does Express work without Node?

No. Express is a Node.js library — it uses Node's http module internally and has no runtime of its own.

Could you use something other than Express?

Yes. Fastify, Koa, and Hono are popular alternatives — all Node.js libraries with different trade-offs in speed and API style.

What does middleware actually do?

Functions that run between the request arriving and your handler executing. Each can read, modify, or short-circuit the request. They chain in order of app.use() calls.
